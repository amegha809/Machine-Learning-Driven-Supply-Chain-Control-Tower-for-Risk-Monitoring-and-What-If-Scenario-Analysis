# Machine Learning-Driven Supply Chain Control Tower

## Project Overview
This project uses machine learning to predict late delivery risk, identify high-risk orders, and compare shipping scenarios to support better supply chain decisions.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Joblib

## Features
- Dataset preprocessing and analysis
- Late delivery risk prediction
- Random Forest and Logistic Regression models
- Feature importance visualization
- High-risk order monitoring
- What-if analysis for different shipping modes

## Dataset
The project uses the DataCo Smart Supply Chain dataset from Kaggle. The original dataset is not included in this repository.

## Current Status
Phase 2 includes model training, risk prediction, model comparison, and shipping scenario analysis.

## Future Scope
- Tkinter-based graphical interface
- Interactive supply chain dashboard
- Improved risk monitoring and scenario analysis
